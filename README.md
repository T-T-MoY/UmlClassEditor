# UML Class Editor

Aplicación Android para crear y editar diagramas de clases UML desde el teléfono.

## Funciones

- Crear clases Java, clases abstractas, interfaces y enumeraciones.
- Editar atributos, métodos, parámetros, visibilidad y tipos.
- Usar tipos primitivos y tipos personalizados.
- Crear relaciones UML: herencia, realización, agregación, composición, asociación, asociación dirigida, asociación bidireccional y dependencia.
- Mover clases y desplazarse o hacer zoom en el lienzo.
- Guardar, importar y combinar proyectos.
- Exportar proyectos como texto o diagramas como imágenes JPG.
- Elegir entre tema claro, oscuro o el tema del sistema.

## Cambios de este fork

- Interfaz y ayuda traducidas al español.
- Controles con esquinas redondeadas.
- Nuevas relaciones UML, incluidas las asociaciones dirigidas y bidireccionales.
- Exportación de diagramas como imágenes JPG.
- Selección de tema claro, oscuro o del sistema.
